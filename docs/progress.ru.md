# AttendBack — выполнение плана

Основание: [утверждённый план](../hackathon-product-plan/development-plan.ru.md).
Пользователь одобрил реализацию всех этапов. Статусы отражают выполненные проверки, а не наличие файлов.

| Этап                 | Статус    | Проверка / следующий результат                                                                                            |
| -------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------- |
| 1. Основа            | Проверено | TypeScript, Vitest, production build; HTTP /api/health = 200 с database:true; worker --once подключился к PostgreSQL 18.4 |
| 2. Правила           | В работе  | Модель состояний, API и схема данных                                                                                      |
| 3. Базовая программа | Ожидает   | Сборка SBF и тесты денежных операций                                                                                      |
| 4. Неявки и споры    | Ожидает   | Проверки переходов и временных границ                                                                                     |
| 5. Сервер            | Ожидает   | Авторизация, роли, конкурентное бронирование                                                                              |
| 6. Worker            | Ожидает   | Повторы, сверка и восстановление                                                                                          |
| 7. Интерфейсы        | Ожидает   | Полный браузерный сценарий                                                                                                |
| 8. Проверки          | Ожидает   | Сквозные проверки и исправления                                                                                           |
| 9. Devnet            | Ожидает   | Конкретное размещение и сетевые роли                                                                                      |

Сейчас отсутствуют подтверждённые параметры публичного размещения и пользовательский кошелёк для devnet-развёртывания. Это не препятствует локальной реализации и проверкам.
