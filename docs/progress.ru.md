# AttendBack — выполнение плана

Основание: [утверждённый план](../hackathon-product-plan/development-plan.ru.md).
Пользователь одобрил реализацию всех этапов. Статусы отражают выполненные проверки, а не наличие файлов.

| Этап                 | Статус    | Проверка / следующий результат                                                                                              |
| -------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 1. Основа            | Проверено | TypeScript, Vitest, production build; HTTP /api/health = 200 с database:true; worker --once подключился к PostgreSQL 18.4   |
| 2. Правила           | Проверено | docs/protocol.ru.md; 4 проверки денежных правил; миграция PostgreSQL применена и повторена                                  |
| 3. Базовая программа | Проверено | SBF + Anchor IDL + Codama; 4 LiteSVM-сценария с реальными SPL-переводами                                                    |
| 4. Неявки и споры    | Проверено | 7 LiteSVM-тестов: споры, временные границы, 0–100% удержания и откат обеих частей выплаты                                   |
| 5. Сервер            | Проверено | 7 серверных тестов + RPC-сценарий v1/v0; 60 заявок на последнее место; восстановление 17 таблиц                             |
| 6. Worker            | Проверено | Crash после сохранения транзакции; повтор тех же байтов; один расчёт; RPC-сбой не освобождает место; worker --once проходит |
| 7. Интерфейсы        | Проверено | Браузер: залог → QR → вход → finalized возврат; адаптивность 375/768/1280; независимый возврат при блокировке API           |
| 8. Проверки          | В работе  | Расширенные сценарии, проверка безопасности и исправления                                                                   |
| 9. Devnet            | Ожидает   | Конкретное размещение и сетевые роли                                                                                        |

Сейчас отсутствуют подтверждённые параметры публичного размещения и пользовательский кошелёк для devnet-развёртывания. Это не препятствует локальной реализации и проверкам.

Этап 7: обе production-сборки проходят; 16 модульных/программных и 10 серверных проверок проходят; 3 браузерных проверки проходят. Камера реализована через getUserMedia + jsQR с ручным вводом; физическое мобильное устройство и HTTPS-домен ещё не проверялись.
