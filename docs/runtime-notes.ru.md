# Проверенные ограничения окружения

- Локальный стенд использует Surfpool 1.6, загруженную SBF-программу и SPL Token. Перезапуск `localnet` сбрасывает цепочку; PostgreSQL сохраняется отдельно. Демонстрационные данные нужно пересоздать после сброса цепочки.
- У Surfpool 1.6 обнаружена заниженная оценка загружаемых данных v1: 139 байт при размере программы 265 KiB. Только для localnet выставлен явный предел 1 MiB; вычислительные затраты по-прежнему оцениваются симуляцией. После подписи backend повторяет симуляцию. Devnet использует обычную оценку Kit.
- Native API Surfpool протестирован с Kit 8.4 и плагинами 0.19. Его необязательные peer-диапазоны для `/kit` пока указывают 0.18; `/kit` entrypoint приложения не используется.
- Служебные подписи localnet используют общедоступные тестовые seed-значения исключительно в памяти. Это не защищённые кошельки; запрещено направлять в них реальные средства. В devnet эти подписи недоступны: требуется сервис подписи и проверенный genesis hash.
- Программа хранит `guest_cancelled` отдельно от статуса возврата. Возврат после посещения сохраняет занятое место, отмена гостем освобождает его после finalized подтверждения.
- Уведомления находятся внутри AttendBack. Внешний email/SMS-провайдер не подключён.
- `pg_dump` и `pg_restore` 18.4 собраны из официального исходного архива; проверка восстанавливает только локальную базу с суффиксом `_test` во временную новую БД и сравнивает содержимое всех таблиц.
